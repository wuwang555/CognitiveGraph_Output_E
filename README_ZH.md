# 认知图输出层（Output Layer）：基于能量动力学的最小可行输出机制

> 本文档描述在《认知的几何、代数与动力学》（以下简称“原论文”）基底之上构建的**输出层模块**。
> **基调与原论文一致：不追求拟合，只追求可算；不判断“意义”，只输出“能量最小”的产物。**

---

## 0. 定位：复杂系统基底的“外部接口”

原论文通过两个公设（认知时空 + 能量最小化），用极简的代码构建了一个能自发涌现出幂律衰减（\(R^2>0.99\)）、Zipf分布（斜率约-1.35）、且跨尺度稳定的**复杂系统基底**。原论文用极度克制的态度，只观察其内部现象（压缩与迁移），证明了其作为思想实验平台的可靠性。

**本模块是原论文基底之上的“外部接口”。** 
它不修改原系统的一阶动力学，只回答一个极简的问题：
> **当外部输入一段先验（Context）时，在这个由能量驱动的复杂系统中，它会自然地流向哪里？**

它的本质是：在原有的全连接能量图上，插入一个“上下文节点”，让它参与演化，最后从它出发寻找**能量最低**的路径。这是复杂系统与外部世界交互的最小可行形式。

---

## 1. 核心机制：看一眼、想一会、给结论

输出层的运行逻辑可以精确概括为：**插入、演化、提取**。

### 1.1 插入（先验输入）
- **动作**：在 G1 图（当前迭代次数 \(T\)）中，插入一个 `__OUTPUT__` 节点。
- **连线**：基于原论文的语义相似度，计算 `Context` 与所有已有概念的相似度。**默认全连接**（保持复杂系统的稠密网络基底），边权按原公式 \(E = 2.0 - 1.5 \times \text{sim}\) 初始化。
- **物理意义**：这就是“**看一眼题**”。先验语义在此刻注入网络。

### 1.2 演化（内部思考）
- **动作**：继续运行 \(N\) 次迭代（默认 10000 次）。
- **机制**：执行原系统的 `basic_energy_optimization`（随机选边降权）和 `apply_basic_forgetting`（向初始值回拉）。
- **物理意义**：这就是“**闭眼思考**”。系统里没有任何语义偏置，纯靠能量梯度和随机游走重塑结构。

### 1.3 提取（输出结果）
- **动作**：从 `__OUTPUT__` 出发，按指定模式（`min_energy` / `longest_path` / `traversal`）寻找路径。
- **物理意义**：输出 = 系统在当前状态下，通往最低能耗邻居的**唯一物理事实**。

## 2. 动态能量预算：绑在演化上的“输出上限”

为了避免拍脑袋决定“路径能走多远”，本模块引入了**动态能量预算（Dynamic Energy Budget）**。

\[
Budget = E_{insert} - E_{final}
\]

- \(E_{insert}\)：插入输出节点时的全局总能量（包含输出节点的边）。
- \(E_{final}\)：演化结束时的全局总能量。
- **物理意义**：系统在 \(N\) 次思考中“省下来”的能量，就是这次输出“能花”的能量。
  - 如果系统没省能量（\(Budget \le 0\)），输出被截断。
  - 如果系统省了极多能量（\(Budget > 0\)），系统就能走一条很长的路径（相当于思考得很深）。

提供两种度量模式：
1. **`total`（总能量）**：预算极大（常常几百），此时路径长度受制于 `max_path_length`，而非能量。
2. **`mean`（平均能量）**：预算极小（约 0.9），此时路径将**真正被局部能量极小值截断**。

---

## 3. 三种输出模式

基于原论文的“硬/软遍历”概念，提供三种提取策略：

1. **`min_energy`（极简输出）**
   只取一条边：`__OUTPUT__ -> 最低能量邻居`。不消耗动态预算。
2. **`longest_path`（深度联想）**
   使用 Beam Search（防止 DFS 指数爆炸），在 `energy_budget` 约束下寻找节点数最多的路径。
3. **`traversal`（软硬混合）**
   按 `hard`（选最小边）/ `soft`（随机选边）/ `mixed`（按比例混合）策略，在 `max_path_length` 和 `energy_budget` 约束下步进。

## 4. 真实运行与现象剖析：为什么输出是“动物级”的？

在真实运行中，我们输入了关于“复杂度分析”的 Context（包含“时间复杂度”等强语义词），并得到了如下的观测：

| 参数 | 数值 |
| :--- | :--- |
| Output node edges | 51 / 51 (全连接) |
| Sim range | 0.0600 ~ 0.3600 |
| 最高 Sim 概念 | 时间复杂度 (0.36) |
| **最终输出路径** | **`__OUTPUT__ -> 队列 -> 分治算法 -> 复杂度理论`** |
| 输出路径总能量 | 0.8025 |

### 现象 1：为什么高语义没胜出？
“时间复杂度”的初始 sim 是 0.36，边权为 1.46；“队列”的 sim 是 0.06，边权为 1.91。
然而，在经过 10000 次完全无偏的随机游走（Poisson 激活，均值 43 次）后，**只要“队列”比“时间复杂度”被多踩 3 次（\(0.9^3 \approx 0.729\)），边权就会反转**。

这恰恰证明了原论文的基底是一个**真正的复杂系统**：它没有语义偏置，只有能量动力学。这就像**“看一眼题目后，闭眼发呆 10000 步”**——初始的语义先验被随机噪声和遗忘机制完全稀释。

### 现象 2：为什么是“队列”？
因为在本次随机游走中，“队列”恰好是该节点路径依赖下最省力的通道。这是一个**物理必然**。它忠实地反映了复杂系统在当前状态下的能量盆地。

## 5. 与上游、下游模块的接口（为什么说它只是“接口”）

**输出层本身不负责“概念生成”或“语义提取”**，这些在原论文的扩展层已经完成。输出层的路径可以直接作为它们的数据源：

1. **喂给 G2（关系图）**：输出层插入的 51 条边可以作为 G2 共现图的初始化源，让后续的不动点检测“抓重点”。
2. **喂给生成图（L3 内心联想）**：如果输出路径经过了若干不动点（如“分治算法”属于某个不动点），则该路径在四维空间的距离序列，就是一次真实的“内心联想”实例。
3. **喂给共识图（社会层）**：\(N\) 个个体输入不同 Context，跑出 \(N\) 条路径，合并到共识图的遍历历史中，计算出一条“社会级共识输出”。

## 6. 边界与声明

1. **不修改原系统**：所有代码都在 `src/output_layer/` 下，原论文代码零修改。
2. **不判断意义**：输出的路径不保证“语义正确”，它只保证“能量最小”。语义的最终解读在人类读者或下游不动点检测器。
3. **全连接保持原图基调**：默认输出节点与所有概念连边，维持原系统稠密图的物理设定。
4. **没有工作记忆**：图就是全部记忆。插入的节点不会“被遗忘”，但它的边权会被动力学稀释。
